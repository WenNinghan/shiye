# 识页桌面版使用说明（Windows x64）

> 发布状态：本仓库当前只发布源码。下文安装器和公式离线包是已完成本机测试的内测产物，暂不提供公开下载；不是仓库缺文件。正式分发前还需许可核对、干净 Windows 验证及签名安排。源码运行请从 [项目 README](../README.md) 开始。

默认在你的电脑识别，不依赖作者电脑开机。可校对文字、表格和印刷公式，导出 Word / Markdown / PDF；重要内容需对照原图，不保证识别全部正确。

## 1. 安装与第一次使用

1. 运行 `Shiye-0.3.0-Windows-x64.exe`，按向导选择安装位置。
2. 双击“识页”。无需另外安装 Python、Node、Office，也不需要保持命令行窗口打开。
3. 首页选择图片/PDF，或先点“用示例体验一下”。
4. 导入后点击“开始识别”，在右侧校对文字、表格和公式。
5. 选择 Word / Markdown / 可搜索 PDF 等格式，先“生成导出文件”，再“下载文件”。

临时文档默认保留 24 小时，请及时导出到自己的文件夹。本轮产物为未签名测试版本；请核实来源，不要关闭系统安全防护。正式公开分发前需核对依赖/模型许可，并完成干净 Windows 安装验证。

## 2. 公式离线包

1. 准备同版本的 `Shiye-Formula-0.3.0-Windows-x64.shiye-model`。
2. 右上角“识别设置” → “导入公式离线包”，选择文件。
3. 选择模型保存目录（需要约 2 GB 可用空间，可选 D/G 盘），等待可信校验值、解压空间、路径和实际模型加载验证。
4. 成功后关闭并重新打开识页；显示“公式引擎已就绪”才可使用。
5. 学术模式可整页找公式，也可框选识别。公式默认数学排版，可对照原图修改。

核心安装器不带公式包，完整离线目录含安装器、公式包和说明。公式未安装不影响普通 OCR。模型保存在你选择的目录内 shiye-models 子目录；安装前检查空间，失败不替换旧模型。不要修改可信校验值绕过验证。

系统临时目录建议至少预留 2 GB。C 盘空间不足时，可先打开 win-unpacked 目录内的识页.exe 使用免安装版；必须保留整个目录，不能只复制 exe。模型另选空间充足的磁盘。

## 3. 自己的 API（可选）

1. 在“识别设置”填写完整 HTTPS endpoint、支持图片的模型名和自己的密钥。
2. 目前支持 Chat Completions 风格的图片输入与 Bearer 密钥；纯文本模型不能识图，不保证所有“兼容服务”字段相同。
3. 点击“保存配置，不发送图片”。密钥默认只在本次运行内存；勾选后才用系统加密记住。
4. 导入后将“识别引擎”切到“自己的 API”。核对目标地址、模型及发送页数，明确同意后才发送。公式框选只发送裁剪区域。
5. 返回后先看候选，确认才采用。整页采用会替换该页原校对内容；不确定就选“保留原内容”。

图片最长边缩放至不超过 2400 像素，细密小字建议裁剪或拆页。无精确坐标时显示“整页来源”，不伪造检测框；公式仍需人工核对。

费用由你与 API 商家结算。应用不代付、不自动切云端、不自动重试。取消无法撤销对方已经开始的处理或费用；重启后未完成的 API 任务需重新确认。

首版只允许公网 HTTPS、443 端口，不支持内网/localhost、查询参数、重定向和隐式代理。连接失败先核对服务商的完整地址、权限和图片支持。

## 4. 隐私与保存

- 默认本机处理；明确选择 API 并同意后才发送所选图片到填写的第三方。
- 密钥不写入源码、文档数据库、导出或普通日志；加密不可用时取消记住，不降级明文。
- Windows 系统加密不能防住同用户权限的恶意程序，不要在不可信电脑填写重要密钥。
- 删除 API 配置移除本机保存的密钥并撤销未发送授权；不会替你撤销供应商后台的 key。
- 不自动迁移开发版文档。卸载默认保留用户数据；临时文档可在最近文档中主动删除。

## 5. 排错

- 启动失败：关闭重开，不要单独搬动 engine 或 DLL。反馈错误提示，不要发送密钥。
- 公式包失败：检查空间、版本、完整性；必须实际模型加载通过，不能只看目录存在。
- API 401/403/429：检查密钥权限、访问限制、余额或限流，确认后再手动重试。
- 公式显示漂亮但内容错误：对照原图核对负号、上下标、括号、矩阵元素。排版正确不等于识别正确。
- Word 不完全像原图：Word 是可编辑的重排文档；保留原画面请选择图片 PDF。

## 6. 开发构建

源码版仍用 `scripts/start.ps1`。开发构建需锁定的 Python 环境、Node 和 `packaging/requirements-build.txt`，用户安装版不需要这些工具。

```powershell
# 在源码根目录执行；路径请替换为你自己的构建环境。
# 先按 README 准备 .venv 与前端依赖，再安装构建工具。
./.venv/Scripts/python.exe -m pip install -r packaging/requirements-build.txt
# 公式环境也需要 PyInstaller；先通过 install-formula.ps1 建立该独立环境。
# 将 -FormulaPython、-FormulaCache 指向 .data/formula-runtime.json 中对应的实际环境与缓存。
./scripts/build-desktop.ps1 -OutputRoot G:/ShiyeBuild -WithFormula -FormulaPython G:/YourFormulaRuntime/Scripts/python.exe -FormulaCache G:/YourFormulaCache
```

构建脚本会生成本机安装产物。`desktop/trusted-models.json` 随公式包重新构建而更新，不能把旧校验值当成自己重建包的校验值。仓库的 `scripts/package_source.py` 是历史 v0.2 源码归档脚本，不覆盖全部桌面目录；获取当前完整源码请使用 Git clone / GitHub Download ZIP。

实际验收及未验证项见 `desktop-acceptance.md`。手机端将在 Windows 版完成后单独设计，当前安装包不能在安卓/iPhone 直接运行。
