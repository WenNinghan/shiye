# 识页路线图

截至 2026-09-16：v0.2 补齐本机学术公式链路；v0.3 增加 Windows 桌面内测、独立运行时、公式离线包导入与可选用户 API。当前发布源码，不宣称所有版面与生产部署阶段都已完成。

## 已实现

上传 / 拖拽 / 截图粘贴；多文件整理；PDF 页码；图像旋转、裁剪、遮盖；持久逐页队列；中文 CPU OCR；原生 PDF 提取；简单有线表格；坐标校对；文字 / 表格 / 图片块编辑；页序 / 块序；六种文档导出；通知候选事项和 ICS；待办草稿；会话隔离；版本保护；过期清理、删除、取消与未完成页重试；以及可选的整页公式定位、框选公式识别、LaTeX / KaTeX 校对、Markdown 数学块和 Word 原生 OMML 公式导出。

## 已调整的技术实现

| 原规划方向 | 本轮落地 | 理由 |
|---|---|---|
| 网页 + Python 处理层 | React/Vite 构建，FastAPI 同源托管 | 本机只需运行一个长期服务 |
| 更强的结构 / 版面引擎 | RapidOCR CPU + 原生 PDF + 简单规则表格；可选 PP-DocLayout + PP-FormulaNet 公式子进程 | 无需付费密钥，本机已实测；公式环境隔离，复杂表格与全篇专业版面仍待增强 |
| 多类实体 / 任务表 | SQLite 文档记录保存版本化页面、任务状态和待办；导出独立索引 | 单 worker 本机版本无需重复同步多张业务表 |
| 暂存与持久化 | 默认 24 小时，手工删除，服务器停机后下次启动继续清理 | 明确运行边界，不暗示关闭电脑后仍后台清理 |

## 下一阶段，按实际需求推进

0. **桌面发布与手机端**：先补全桌面依赖/权重许可清单、干净 Windows 验证、真实 API 提供方验证；再确定手机网页或安卓/iPhone APP 路线。当前响应式页面不等于独立手机应用，手机端不能直接运行 Windows 模型包。

1. **专业版面质量**：复杂表格与合并单元格；跨行段落、双栏阅读顺序；透视纠正、曲面展开；行内小公式与更复杂公式结构。是否引入完整 PP-Structure / MinerU 应先以真实样本对比，不替换已经验证的轻量默认链路。
2. **生产部署**：账户与权限、资源总配额、完整解码进程隔离、分布式队列、对象存储、HTTPS、监控、恶意样例验证。先明确部署主机和用户规模，不自动购买或发布。
3. **实测评估**：收集经过授权和脱敏的真实文档，建立人工真值，按中文 CER、表格结构、版式与导出可用性分别评测。规划中的 60 份材料尚未采集。
4. **高阶待办**：跨行通知关联、语义理解、会议持续时间、更多日期表达、日历客户端兼容性。提醒和账号同步必须有单独明确授权。
5. **体验完善**：工程备份导入、长文档分页读取、增量块级保存、批量下载、撤销操作、屏幕阅读器与键盘专项验收。
